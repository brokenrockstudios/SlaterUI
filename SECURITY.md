# Security Policy

## Supported Versions

SlaterUI is currently in active development. Security fixes are generally targeted at the latest version on the `main` branch.

Older versions and individual commits are not guaranteed to receive security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in SlaterUI, please report it privately to **support@brokenrockstudios.com**.

Please include, when possible:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- The affected version or commit.
- Any relevant logs, examples, or proof-of-concept code.

Please avoid publicly disclosing security vulnerabilities before maintainers have had an opportunity to investigate and address them.

Reports will be reviewed as time permits. Confirmed vulnerabilities will be prioritized based on severity and impact, with fixes and disclosures coordinated as appropriate.

For ordinary bugs or issues without security implications, please use [GitHub Issues](https://github.com/brokenrockstudios/SlaterUI/issues).
